# PP2 - fast image comparison tool for devs by devs

## Usage examples

```shell
node screenshot.js --url=https://stackoverflow.com/ --path=./screenshot.png --width=320 --height=1000
node screenshot.js --url=https://stackoverflow.com/ --path=./screenshot.png --fullPage
node screenshot.js --url=https://stackoverflow.com/questions/52553311/how-to-set-max-viewport-in-puppeteer/ --path=./screenshot.png --selector="#answer-52561280"   
```
